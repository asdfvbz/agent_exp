给经验库做体检。

```bash
python "${CLAUDE_PLUGIN_ROOT}/exp.py" gc
```

`gc` 会报出三类问题,**每一类的处置方式不同**:

| 信号 | 含义 | 该怎么办 |
|---|---|---|
| **反复复发** | 注入了还是犯 | **fix 不可执行** —— 重写 fix,别加新经验 |
| **检索漏检** | 该命中没命中 | **触发词写偏了** —— 用你实际会想到的词重写 |
| **死重** | 30 天 0 命中 | 触发词偏了,或本来就不该记 —— 删或合并 |

处理时遵守:

- **不要自动删除。** 报告给用户,让他决定。库的改动应该有人过目。
- **被推翻的经验保留,不要删。** 它防止重新相信同一个错误 ——
  这比一条正确的经验更有价值。
- **优先修「反复复发」,而不是加新经验。** 一条失效的经验会持续污染
  每一次注入。库的价值不是条数,是被命中过多少条。

如果用户想边看边处理,开网页:

```bash
python "${CLAUDE_PLUGIN_ROOT}/exp.py" serve
```

网页上每条经验都会显示健康度徽章和「注入 / 复发 / 漏检」计数,
点开是全文。
