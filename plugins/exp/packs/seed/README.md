# seed —— 起步包

跨项目通用的坑。每一条都满足:**换任何仓库都成立**,且**犯了不会立刻报错**。

装了这个包,空库第一天就有东西可检索 —— 冷启动是这类工具的头号杀手。

```bash
exp pack install seed
```

装到**全局层**(默认),所有项目都能用到。

## 包含什么

| 经验 | 为什么它是坑 |
|---|---|
| 虚构字符会静默毁掉 YAML 解析 | 报错指向别处,一个字符让四五个工具同时报错 |
| 阈值必须有来源 | 没人会回头质疑一个已经写进配置的数字 |
| LLM 评分是带噪声的信号 | 看起来像客观判决,其实跨判定线只差一次采样 |
| 度量工具必须覆盖所有输入形态 | 漏报时它报 0,而 0 看起来很正常 |
| 改了源文件必须回写派生文件 | 没有任何自动检查能发现这种脱节 |
| 散列应基于语义而非原文 | 格式调整被误判为内容变更,告警变噪声 |
| 聚合指标不能当逐项门禁 | 数学上不可能全满足,逼着你去造假 |
| CLI 输出符号会撞上非 UTF-8 控制台 | 工具直接崩,而不是"检查没通过" |

## 它们是起点,不是结论

装进来的经验带着原作者环境下的 `status`。
**别人的 `confirmed` 不等于在你的环境里 confirmed。**

真正属于你的信号是你在使用中积累出来的 `recurred` / `missed` ——
那才是 `exp gc` 会拿给你看的东西。
